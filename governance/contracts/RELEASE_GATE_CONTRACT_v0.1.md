# Release & Phase Gate Contract v0.1

A gate is a control point, not a calendar milestone.

## Gate outcomes
- PASS
- PASS_WITH_CONDITIONS
- BLOCKED
- FAIL

## Minimum gate review
1. Required work items completed.
2. Required artifacts registered.
3. Dependencies satisfied.
4. Acceptance criteria verified.
5. Evidence registered.
6. Known risks documented.
7. No unresolved Constitution conflict.

A later phase may not be treated as active until its entry gate passes.
