# Requirement Traceability Contract v0.1

## Requirement ID taxonomy
- BR: Business Requirement
- PR: Product Requirement
- FR: Functional Requirement
- NFR: Non-functional Requirement
- DR: Data Requirement
- AIR: AI Requirement
- SEC: Security Requirement
- UXR: UX Requirement
- PAY: Payment Requirement
- OPS: Operational Requirement

## Trace path
Business need -> Requirement -> Architecture/Design -> Component/Function -> Test -> Evidence -> Release.

No production feature is complete without a requirement ID and verification evidence.
Requirements are elaborated progressively; P00 does not invent detailed implementation requirements.
