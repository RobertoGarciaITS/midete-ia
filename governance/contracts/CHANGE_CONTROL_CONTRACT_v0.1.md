# Change Control Contract v0.1

## Applies to
Frozen constitution, approved scope, approved architecture, baselined requirements, controlled schemas, release gates.

## Change Request minimum
- CR ID
- requester
- proposed change
- rationale
- affected artifacts
- scope/time/cost/security/data/commercial impact
- compatibility/migration impact
- recommendation
- approval decision

## Rule
No approved baseline is silently edited. Approved changes create new versions and update registries/dependencies.
