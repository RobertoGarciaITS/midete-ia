# P00 Project Governance Prompt v0.1

## Objective
Establish a controlled repository baseline that allows humans and multiple AI/coding agents to work incrementally without losing project context, dependencies, evidence, or approval boundaries.

## Authorized scope
- Freeze Constitution v0.1.
- Establish canonical repository structure.
- Create governance contracts.
- Create artifact/prompt/skill/dependency/evidence registries.
- Create gate model.
- Create Project Execution Manifest.
- Create Project Work Traceability Matrix.
- Verify P00 artifacts and decide GATE-P00.

## Explicitly out of scope
Product feature design beyond baseline, application code, APIs, database schemas, AI implementation, payment integration, Docker/Kubernetes/cloud resources.

## Completion criteria
All P00 work items P00-01..P00-09 have controlled artifacts, dependency status, acceptance result and evidence; GATE-P00 can be evaluated.
